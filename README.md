- **Valuation ถูกมาก:** ที่ราคา `181.00 บาท` เทรดที่ **`P/BV 0.60 เท่า`** (ลดราคา 40% จาก Book Value) และ `P/E 7.51 เท่า` พร้อมเงินปันผล `10.00 บาท/หุ้น` (`Gross Yield 5.52%`) จาก Payout เพียง `41.5%`
- **จังหวะกราฟ (`TF 1M`):** ย่อตัว (`Throwback`) 2 แท่งเดือนจากยอด `204.0 บาท` ลงมาทดสอบแนวรับ `172.0–181.0 บาท` ด้วย Volume ที่หดตัวลง และ `RSI 1M = 59.36` ยังไม่ Overbought

### 2. 🦅 ธนาคารกรุงไทย (`KTB`) — พื้นฐานระดับ Super Bank แต่ราคาวิ่งนำพื้นฐานไปแล้ว
